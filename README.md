# xlmeta

**엑셀 수식에서 업무 지표 정의를 추출해 [OKF](https://github.com/GoogleCloudPlatform/knowledge-catalog) 번들로 출력합니다. LLM을 쓰지 않습니다.**

회사의 실제 업무 규칙은 규정집이 아니라 담당자의 엑셀 수식 안에 있습니다.
`SUMIFS(실적!G:G, 실적!F:F, "승인")` — 승인된 건만 원가로 인정한다는 규칙이 어디에도
문서화되어 있지 않은 채 셀에 박제되어 있습니다.

수식은 이미 형식언어이므로 추론할 필요가 없습니다. 파싱하면 됩니다.

## 빠른 시작

```bash
pip install -r requirements.txt   # openpyxl 하나

python make_sample.py             # 데모용 엑셀 생성 → sample_epc_cost.xlsx
python -m xlmeta sample_epc_cost.xlsx -o demo
```

`demo/`에 마크다운 지식 번들이 생성됩니다. 자기 파일로 돌리려면:

```bash
python -m xlmeta report.xlsx -o okf_bundle
```

> 샘플 엑셀은 리포지터리에 바이너리로 넣지 않고 [`make_sample.py`](make_sample.py)로
> 재현합니다. 누구나 같은 입력으로 같은 결과를 다시 만들 수 있습니다.

### 웹 데모

엑셀을 올리면 xlmeta가 읽어낸 **구조를 원본과 나란히** 보여주는 얇은 Flask 화면입니다.
복잡한 실무 엑셀을 다른 시스템으로 옮기기 전에 "이 파일이 실제로 어떤 구조인지" 파악하는 용도.

```bash
pip install -r webapp/requirements.txt
python webapp/app.py            # → http://127.0.0.1:5000
```

파일 없이 **"샘플 데이터로 체험"** 버튼으로 즉시 둘러볼 수 있습니다. 두 개의 탭:

- **① 구조** — 왼쪽에 실제 엑셀 격자(셀을 빈칸·숫자·텍스트·수식 유형으로 색칠), 오른쪽에
  뽑아낸 구조(표 영역·다단 머리글·행 식별 열·소계행·시트 참조). 오른쪽 영역을 클릭하면
  왼쪽 원본에서 해당 범위가 하이라이트됩니다.
- **② 지표·규칙** — 수식에서 추출한 업무 규칙·매칭 키·수기 개입·지표 의존 그래프와 원본 OKF 마크다운.

핵심 도구(`xlmeta`)는 그대로 호출만 하므로, 웹은 선택적 껍데기입니다.

#### AI에게 넘기기

엑셀을 올리면 구조·업무규칙을 **결정론적으로 요약**해 공개 페이지(`/s/<id>`)로 만들고,
그 링크를 **ChatGPT·Claude 프리필**에 담아 넘깁니다. 요약이 URL이 아니라 링크가
가리키는 페이지에 있어 주소가 길어지지 않습니다. (원시 데이터 값은 담지 않고 구조·규칙만.)

#### 배포 (Docker + AWS EC2)

```bash
docker compose up -d --build     # → http://localhost (EC2에선 공개 주소)
```

`ProxyFix`가 걸려 있어 리버스 프록시(ALB/Caddy) 뒤에서 `https://도메인` 링크가
그대로 나옵니다. 자세한 EC2 절차는 [`DEPLOY.md`](DEPLOY.md) 참고.

## 무엇을 뽑는가

| | 내용 |
|---|---|
| **업무 규칙** | `SUMIFS` 계열 조건 → "결재상태 = 승인" |
| **수기 개입** | 수식이 있어야 할 자리의 상수 → 자동화하면 안 되는 지점 |
| **하드코딩 상수** | 수식에 박힌 임계값 |
| **지표 의존 그래프** | 셀 단위가 아니라 지표 단위 |
| **소계/합계 제외** | 집계 행을 지표로 오인하지 않음 |

### 예시 결과

`발생원가` 지표 하나의 수식 `=SUMIFS(실적!G:G,실적!C:C,A6,실적!F:F,"승인")` 에서 뽑아낸 것:

- **업무 규칙** — 결재상태 `=` 승인
- **매칭 키** — 프로젝트코드 = `A6`
- **원천** — `실적!G:G`(금액), `실적!C:C`(프로젝트코드), `실적!F:F`(결재상태)
- **수기 개입** — `원가현황!D9` 에 사람이 박은 값 `1,875,000,000` (사유 메모까지 포착)
- **이 지표를 쓰는 곳** — 집행률, 총투입예상

전체 생성물은 [`demo/`](demo/) 에서 볼 수 있습니다.
([`demo/metrics/발생원가-M001.md`](demo/metrics/발생원가-M001.md) 부터 보세요.)

## 승인 레이어 — "이 정의는 담당자가 확인함"

추출만으로는 부족합니다. **틀린 정의가 승인된 채로 AI에게 가는 것**이 최악이니까요.
그래서 승인을 **이름이나 셀 주소가 아니라 정의의 '내용'에 붙입니다.**

```bash
python -m xlmeta report.xlsx --approve 발생원가 --by 홍길동   # 담당자가 승인
python -m xlmeta report.xlsx -o okf_bundle                   # 승인/대기 상태로 출력
```

정의를 **정규화**해 지문(fingerprint)을 만듭니다. 셀 주소·시트 이름·행 개수는 지우고
**구조와 조건만** 남깁니다:

```
초과율 =(H6-G6)/G6   →  (발생원가 - 실행예산) / 실행예산  →  해시 d4f2a1…
```

이 지문에 승인이 붙으므로:

| 바뀐 것 | 지문 | 승인 |
|---|---|---|
| 행이 밀림 (프로젝트 추가) | 그대로 | **유지** |
| 시트 이름 `실적`→`실적_2026` | 그대로 | **유지** |
| 조건 `"승인"`→`"완료"` | **달라짐** | **자동 만료 → 대기** |
| 분모에 예비비 추가 | **달라짐** | **자동 만료 → 대기** |

**변화 감지와 승인 만료가 같은 한 장치입니다.** 사람이 "어? 이거 바뀌었나?" 하고
알아챌 필요가 없습니다. 기본값이 대기(pending)라, 변화를 놓쳐도 틀린 정의가 AI에게
가지 않습니다. 승인 상태는 각 지표 문서와 [`index.md`](demo/metrics/index.md)에 ✅/⏳로 표시됩니다.

## 구조

```
xlmeta/
├── xlmeta/            파이썬 패키지
│   ├── layout.py      표 구조 해석 (수식을 모름)
│   ├── formula.py     수식 파싱 (표 구조를 모름)
│   ├── metric.py      둘을 결합해 지표 구성
│   ├── explain.py     사람·AI용 해석 (한글 설명·함수 문법·Python 변환)
│   ├── fingerprint.py 정의 내용 기반 지문 (승인 유지/만료)
│   ├── approvals.py   지문에 붙는 승인 저장소
│   ├── emit_okf.py    OKF v0.1 번들 출력
│   └── __main__.py    CLI 진입점 (python -m xlmeta)
├── make_sample.py     데모용 엑셀 생성기 (재현용)
├── webapp/            업로드→분석→번들 탐색 Flask 화면 (선택)
├── demo/              예시 출력 번들
└── docs/              주석 달린 예시 문서
```

레이아웃이 먼저입니다. 표 영역·다단 머리글·소계행을 확정한 뒤에야 수식을 해석합니다.
셀을 값이 아니라 유형(`. n t f`)으로 바꾼 지도에서 시작하므로 내용을 몰라도 모양이 보입니다.

`layout.py`는 수식 내용을 전혀 모르고, `formula.py`는 표 구조를 전혀 모릅니다.
둘을 아는 모듈은 `metric.py` 하나뿐입니다. 이 관심사 분리 덕분에 한쪽을 고쳐도
다른 쪽이 깨지지 않습니다.

## 원칙

- **추론하지 않는다.** 같은 입력이면 같은 출력. 재실행으로 검증 가능.
- **침묵 누락 0.** 이름을 확정하지 못하면 추측 대신 제외하고 `index.md`에 명시합니다.
- **오프라인.** 의존성은 `openpyxl` 하나. 폐쇄망에서 돌고 데이터가 나가지 않습니다.

## 한계

- 피벗 테이블, 배열 수식, 외부 파일 링크 미지원 (감지 후 보고)
- 행 방향 표(좌측 항목 / 상단 기간) 미지원
- 계층형 행머리글 미지원
- 수식 계산값은 엑셀이 저장한 캐시에만 존재합니다. openpyxl로 만든 파일은
  캐시가 없어 `sample_value`가 비어 있을 수 있습니다(규칙 추출과는 무관).
