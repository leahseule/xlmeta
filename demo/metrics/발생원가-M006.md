`경영요약!B2:B6` · 원본 수식 `=SUMIFS(실적!G:G,실적!C:C,A2)`

# 계산 설명

실적 시트에서 프로젝트코드가 같고 행의 금액을 모두 더한 값이에요.

# 쓰인 함수

| 함수 | 설명 | 문법 |
|---|---|---|
| `SUMIFS` | 여러 조건을 모두 만족하는 행의 값만 더해요. | `SUMIFS(합계범위, 조건범위1, 조건1, [조건범위2, 조건2], …)` |

# Python

정확히 변환 가능한 계산만 제공. 복잡한 수식은 지어내지 않음.

```python
sum(row["금액"] for row in 실적 if row["프로젝트코드"] == 이_행["프로젝트코드"])
```

# 매칭 키

- 프로젝트코드 = `A2`

# 원천

| 참조 | 의미 |
|---|---|
| `실적!G:G` | 금액 |
| `실적!C:C` | 프로젝트코드 |
| `경영요약!A2` | 프로젝트코드 |
