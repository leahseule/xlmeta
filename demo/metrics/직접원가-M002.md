`원가현황!E6:E11` · 원본 수식 `=SUMIFS(실적!G:G,실적!C:C,A6,실적!D:D,"직접비",실적!F:F,"승인")`

# 계산 설명

실적 시트에서 프로젝트코드가 같고, 계정이 ‘직접비’인, 결재상태가 ‘승인’인 행의 금액을 모두 더한 값이에요.

# 쓰인 함수

| 함수 | 설명 | 문법 |
|---|---|---|
| `SUMIFS` | 여러 조건을 모두 만족하는 행의 값만 더해요. | `SUMIFS(합계범위, 조건범위1, 조건1, [조건범위2, 조건2], …)` |

# Python

정확히 변환 가능한 계산만 제공. 복잡한 수식은 지어내지 않음.

```python
sum(row["금액"] for row in 실적 if row["프로젝트코드"] == 이_행["프로젝트코드"] and row["계정"] == "직접비" and row["결재상태"] == "승인")
```

# 업무 규칙
