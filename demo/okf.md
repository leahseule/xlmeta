## 지표

### 발생원가

- 적용 범위: `원가현황!D6:D11`
- 원본 수식: `=SUMIFS(실적!G:G,실적!C:C,A6,실적!F:F,"승인")`
- 계산 설명: 실적 시트에서 프로젝트코드가 같고, 결재상태가 ‘승인’인 행의 금액을 모두 더한 값이에요.
- 업무 규칙: 결재상태 = 승인
- 매칭 키: 프로젝트코드 = A6
- 원천: `실적!G:G`(금액), `실적!C:C`(프로젝트코드), `원가현황!A6`(프로젝트코드), `실적!F:F`(결재상태)
- 수기 개입: `원가현황!D9`=1875000000
- 쓰이는 곳: 집행률, 총투입예상

```python
sum(row["금액"] for row in 실적 if row["프로젝트코드"] == 이_행["프로젝트코드"] and row["결재상태"] == "승인")
```

### 직접원가

- 적용 범위: `원가현황!E6:E11`
- 원본 수식: `=SUMIFS(실적!G:G,실적!C:C,A6,실적!D:D,"직접비",실적!F:F,"승인")`
- 계산 설명: 실적 시트에서 프로젝트코드가 같고, 계정이 ‘직접비’인, 결재상태가 ‘승인’인 행의 금액을 모두 더한 값이에요.
- 업무 규칙: 계정 = 직접비, 결재상태 = 승인
- 매칭 키: 프로젝트코드 = A6
- 원천: `실적!G:G`(금액), `실적!C:C`(프로젝트코드), `원가현황!A6`(프로젝트코드), `실적!D:D`(계정), `실적!F:F`(결재상태)

```python
sum(row["금액"] for row in 실적 if row["프로젝트코드"] == 이_행["프로젝트코드"] and row["계정"] == "직접비" and row["결재상태"] == "승인")
```

### 집행률

- 적용 범위: `원가현황!G6:G11`
- 원본 수식: `=D6/F6`
- 계산 설명: 이 값은 계산식 그대로예요: 발생원가 ÷ 예산
- 원천: `원가현황!D6`(발생원가), `원가현황!F6`(예산)
- 재료(참조 지표): 발생원가

```python
발생원가 / 예산
```

### 예비비

- 적용 범위: `원가현황!H6:H11`
- 원본 수식: `=F6*0.05`
- 계산 설명: 이 값은 계산식 그대로예요: 예산 × 0.05
- 원천: `원가현황!F6`(예산)
- 하드코딩 상수: `0.05`
- 쓰이는 곳: 총투입예상

```python
예산 * 0.05
```

### 총투입예상

- 적용 범위: `원가현황!I6:I11`
- 원본 수식: `=D6+H6`
- 계산 설명: 이 값은 계산식 그대로예요: 발생원가 + 예비비
- 원천: `원가현황!D6`(발생원가), `원가현황!H6`(예비비)
- 재료(참조 지표): 발생원가, 예비비

```python
발생원가 + 예비비
```
